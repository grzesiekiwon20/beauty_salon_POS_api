# 🌸 Beauty Salon POS API

A **Point of Sale (POS) API for beauty salon systems** — backend service for managing salon operations such as products, services, sales, staff and client data.

> ⚠️ **Warning:** This project is **unfinished** and **not ready for production use**. It’s a work in progress and should *not* be used in real-world or commercial environments.

---

## 📌 Project Overview

The `beauty_salon_POS_api` repository contains source code for a Java-based REST API aimed at supporting POS functionality for beauty salons. This API is intended to provide the backend logic that a frontend application (mobile app, web dashboard, or POS terminal client) can use to manage salon operations.

**Tech Stack**
- Java (backend)
- Maven (project build)

**Main Features Planned**
✔ User management  
✔ Product and service management  
✔ Sales and transaction records  
✔ Appointment scheduling  
✔ Staff & role permissions  
> This is a developing roadmap and may change as the project advances.

---
